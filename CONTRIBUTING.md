# Contributing to DjangoShop

Thank you for considering contributing to DjangoShop! We welcome your input and ideas.

## Reporting Bugs
If you encounter a bug in DjangoShop, please follow these steps:
1. Check the [issues](https://github.com/Morteza689/DjangoShop/issues) to see if the bug has already been reported.
2. If it hasn’t, open a new issue and provide the following information:
   - A clear and descriptive title
   - Steps to reproduce the issue
   - Expected behavior
   - Actual behavior
   - Screenshots, if applicable

## Suggesting Enhancements
To suggest an enhancement:
1. Search the existing issues to see if your idea has already been proposed.
2. If it hasn’t, open a new issue with a clear title and description of the enhancement you'd like to see.

## Submitting Pull Requests
When you’re ready to submit a pull request:
1. Fork the repository to your own GitHub account.
2. Create a new branch for your feature or fix: `git checkout -b your-feature-branch`
3. Write meaningful commit messages that describe the changes you made.
4. Make sure your code adheres to our [code style guidelines](#code-style-guidelines).
5. Push your changes to your fork: `git push origin your-feature-branch`
6. Open a pull request in the original repository and describe your changes.

## Code Style Guidelines
To maintain a consistent codebase:
- Follow the [PEP 8](https://www.python.org/dev/peps/pep-0008/) guidelines for Python code.
- Ensure that your code is well-documented with comments and docstrings.

## Development Setup Instructions
To set up a local development environment for DjangoShop:
1. Clone the repository:
   ```bash
   git clone https://github.com/Morteza689/DjangoShop.git
   cd DjangoShop
   ```
2. Create a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the development server:
   ```bash
   python manage.py runserver
   ```
5. Start contributing!
